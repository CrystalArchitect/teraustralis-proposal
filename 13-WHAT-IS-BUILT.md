### Running now — verified on a fresh machine, dates given

- **The CrystalCore engine** (Python, open repository). A message bus whose
  validator rejects any message that does not declare its evidence layer; a
  consent gate that is fail-closed and revocable at runtime; memory kept
  separate from any model, so models remain swappable faculties. Four core
  test suites pass 51/51 and Lumina's core tests 16/16 on a fresh clone
  (verified 24 July 2026); a 7/7 bridge selftest was added to CI the same
  day. CI runs the suites on every push.
- **A live, indexed site** — [www.teraustralis.com.au](https://www.teraustralis.com.au):
  self-generating sitemap, IndexNow notification on every deploy. Retrieved
  and cited as a source by Perplexity roughly 48 hours after DNS went live,
  recorded verbatim in the archive (8 August 2026).
- **Provenance anchored to Bitcoin.** A deterministic SHA-256 manifest over
  the creative canon, timestamped via OpenTimestamps by CI, with each proof
  committed back into the repository (first proofs 31 July 2026). No wallet,
  no token, nothing traded — pure timestamping, verifiable by anyone with
  the repository and an `ots` client.
- **Two reproducible studies of AI behaviour** (filed 8 August 2026): a
  four-round test of AI-delivered code against its own claims — each version
  run exactly once and reported honestly, until claims and code converged —
  and an eleven-way comparative record of AI responses to a single two-word
  prompt. The study code is standard-library Python, deterministic, and
  included in the public record.

### Built, awaiting hardware — stated plainly

- **Clementine**, the companion application a person actually talks to:
  local-first, and previously ran end-to-end on local models via Ollama.
  After a hardware loss, the recovered package (v0.13.4) imports cleanly and
  passes 19 of 20 offline tests on a fresh machine (24 July 2026). A full
  local-model session on new hardware is the next verification step.

### Designed, deliberately not built — labelled Vision

The Lattice substrate, the node mesh, and the full TerAustralis vision are
locked by the project's own Constitution as designed, not built, and every
status document says so. The portfolio's ledger opens with its rule: *"This
file describes the state of the system, not the ambition of the system."*

### Governance you can audit

- **Consent is a runtime property.** A public credit ledger where people
  enter only by their own evidenced public words — scoped to exactly what
  was asked, reversible at any time, no reason required. Models cannot
  consent; AI-generated texts are filed as received documents with authority
  weight zero, never as members or evidence.
- **Indigenous Data Sovereignty is a hard boundary**, designed in from the
  start: *"Not AI that contains Songlines. AI infrastructure capable of
  respecting the laws that already govern them."* Practised, not only
  stated: work is held back whenever the consent door belongs to custodians
  rather than to the project.
- **A creative canon under settled rights** — nineteen recordings catalogued
  with per-track rights fixed by dated receipts (8 August 2026), including
  one work removed because the grant was not the project's to make.

### Prior art, conceded

Local-first assistants and companion applications are a crowded, healthy
field; no claim is made to that ground. The narrower, checkable claim is the
governance layer enforced at runtime — evidence-labelled messaging,
fail-closed consent, model-agnostic identity — with the entire record
public, dated, and independently verifiable.
